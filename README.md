# MnCatalase-Python-codes
The Barplot-ManganeseCatalase.py is used for generating barplots from geometric data obtained by NACCESS and electrostatic data obtained by Rosetta. 
The CavityPolarityProgram.py is used to obtain the amino acid composition of the cavity surface and provide cavity polarity
The DistInterfacesFromCatalyticSite.py provides distance between the interfaces and catalytic site.
The MDsimulationHbondMnCatalase.py uses MDsimulation frames to calculate stable Hbonds.
The MnCatHelixTurnSheetMolarExtinction.py calculates percent secondary structure components and molar extinction coefficient.
The MnCatalaseCOMMetalBindingSite.py calculates COM of catalytic sites using the coordinates of residues involved in metal binding.
The MnCatalase_InterfaceGeometry.py uses NACCESS data to calculte BSA, Interface Atoms, Resiues and Local Atomic Density.
The Protparam MnCatalase.py tries to use protein sequence data to obtain GRAVy and other hydrophobicity data.
The ShortestDistanceBetweenActivitySiteCoMandInterface.py caculates the shortest distance between catalytic site CoM and Interfaces
